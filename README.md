# Qinkunex

### Human–Object Interaction & Interface Engineering

We explore new ways for people to interact with the objects, spaces, and systems around them.

---

## Built with Sanytron

Qinkunex is a technology and design initiative behind selected Sanytron projects.

Our work explores how people interact with their environments through intelligent interfaces, physical controls, connected devices, and software ecosystems.

From the smart home to the desktop, we build tools that make technology more accessible, adaptable, and useful in everyday life.

---

## Our Ecosystems

### 🎛️ Astrion — Smart Home Interface

A dedicated physical interface for Home Assistant, bringing touch, voice, and tactile controls together in one purpose-built device.

Astrion is designed to make smart home interaction more direct and intuitive, without relying entirely on a smartphone.

**Explore the Astrion software ecosystem:**

- [RosCard](https://github.com/yyqclhy/RosCard) — Custom Home Assistant UI cards designed for Astrion and remote-first smart home control.
- [Astrion Integration](https://github.com/yyqclhy/Astrion-integration) — Home Assistant integration for Astrion Remote.

**Resources:** [Astrion Support](https://hub.sanytron.com/) · [Community Forum](https://forum.sanytron.com/)

---

### 🖥️ UltraBARX — Modular Desktop Ecosystem

A modular desktop command center designed for applications, automation, AI, and smart home control.

UltraBARX brings together physical modules, desktop software, and an expanding ecosystem of creator-built experiences.

**Explore the UltraBARX ecosystem:**

- [UltraWorkspace](https://github.com/Qinkunex/UltraWorkspace) — Desktop configuration and control software for UltraBARX hardware.
- [UltraBARX Open Platform](https://open.ultrabarx.sanytron.com/) — A platform for creators to submit, publish, and manage apps, plugins, and wallpapers for the UltraBARX ecosystem.

**Resources:** [UltraBARX Support](https://hub.sanytron.com/) · [Community Forum](https://forum.sanytron.com/)
